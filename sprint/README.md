Tecnologias usadas: Vite + React + Tailwind CSS

Para instalar as dependências é só rodar o comando: "npm install" no terminal

Para executar o projeto é só rodar o comando: "npm run dev" no terminal

Utilizamos a IA principalmente para uma revigoração no design, contendo UX e UI, dúvidas em sintaxes e recomendações de API ou nos dados puxados da API.
